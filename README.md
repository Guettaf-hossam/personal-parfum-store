# دار العطور الفاخرة | MAISON DE PARFUM

متجر إلكتروني فاخر ومستقل للعطور الشرقية وعطور النيش، مزود بلوحة تحكم ذاتية الإدارة (`/admin`) وقاعدة بيانات Supabase ونظام طلب مباشر وسلس عبر WhatsApp.

---

## الميزات الرئيسية

- **الواجهة العامة للمتجر (`/`)**:
  - تصميم عصري فاخر وداكن مع دعم كامل للوضع الليلي والنهاري (Dark/Light Mode).
  - دعم ثنائي اللغة (العربية افتراضياً مع `dir="rtl"` والفرنسية).
  - شبكة منتجات مرنة ومتجاوبة للأجهزة المحمولة مع فئات تصفية ديناميكية.
  - بطاقات منتجات بنسبة `4:5` مع علامات الحجم والتخفيض ومؤشر المنتجات المميزة.
  - نافذة طلب سريعة ومنبثقة ترسل الطلب مباشرة عبر WhatsApp مع حقول الاسم، الهاتف، واختيار ولاية التوصيل من بين 58 ولاية جزائرية.
  - إمكانية نسخ ومشاركة رابط مباشر لأي عطر (`#product-<id>`).

- **لوحة التحكم ذاتية الإدارة (`/admin`)**:
  - مسار محمي عبر مصادقة Supabase Auth (البريد الإلكتروني وكلمة المرور).
  - إضافة وتعديل وحذف المنتجات بسهولة.
  - رفع الصور مع ضغط فوري داخل المتصفح بتقنية WebP بجودة عالية وحجم خفيف.
  - تبديل حالة ظهور العطر في المتجر بنقرة واحدة (نشط / مخفي).

- **قاعدة البيانات والتخزين**:
  - مخطط SQL كامل لـ Supabase (`supabase/schema.sql`) مع سياسات الأمان على مستوى الصف (RLS).
  - دلو تخزين مخصص لصور العطور (`product-images`).

---

## التشغيل والتثبيت

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# فحص الأنواع
npx tsc --noEmit

# بناء المشروع للإنتاج
npm run build
```
